# CS Digital Classroom — Topic Visuals fix

Upload `index.html`, `teacher.html`, and `board.html` to the root of your GitHub Pages repository, replacing the older copies. The diagrams are now drawn directly within Teacher and Board: there is no images folder, image URL, or separate script to upload.

After GitHub Pages updates, refresh both devices. On the classroom display press Ctrl+Shift+R (or Ctrl+F5) for a fresh copy; on Android Chrome, close and reopen the page if it still shows an older version. The Topic Visuals panel should show two labelled diagrams instead of broken-image icons.

To pair: start Teacher with a six-digit code and wait until it says ready. Enter the same code on Board and tap Connect. Board displays the lesson even before connection and retries if Teacher starts later. The models, component explanations, note-linked 3D concepts, activities and quizzes remain in the three HTML files.

The site contains 10 topics, 50 switchable 3D views, 99 note-linked concepts, 20 diagrams and 10 interactive experiments. Lesson content can load without Internet; Teacher/Board pairing requires Internet for PeerJS signaling and a network permitting peer connections. Speech depends on browser support.
