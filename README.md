# CS Digital Classroom — Smooth 3D transitions

Upload `index.html`, `teacher.html`, and `board.html` to the root of your GitHub Pages repository, replacing the older files. Refresh both devices after GitHub Pages updates; use Ctrl+Shift+R on the classroom display.

## What changed

- Switching among a topic's five 3D views fades the old model away and the new model in.
- Topic text and teaching sections enter smoothly when the lesson changes.
- Auto rotation uses animation frames for steadier motion. Finger or mouse dragging follows the pointer immediately, and Reset view restores the initial angle.
- Tapping a component highlights it while its written and spoken explanation appears. On devices set to reduced motion, unnecessary animation is disabled.

Teacher and Board still use the same six-digit code. Board shows **Synced: topic N** and a session label only after it receives the lesson; Teacher shows **Board synced** after the acknowledgement. The current lesson is resent regularly in case an update is missed.

The site includes 10 topics, 50 switchable 3D views, 99 note-linked concepts, 20 embedded diagrams and 10 activities. Pairing requires Internet and a network that permits peer connections. Browser speech support varies; written explanations are always available.
