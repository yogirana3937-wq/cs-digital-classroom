# CS Digital Classroom — 50 interactive 3D views

Upload `index.html`, `teacher.html`, and `board.html` together to the root of your GitHub Pages repository, replacing the older files. Activities and diagrams are embedded; no images or JavaScript folder is needed.

## How to teach with it

1. On Teacher, enter a six-digit classroom code and tap Start Classroom. On Board, enter the same code and tap Connect.
2. Choose a topic. Its 3D lab has an overview, two focused models and two Concepts views. Tap a component to show and hear its explanation. Use the Component voice button to turn speech on or off on each device.
3. Under Detailed Teaching Notes, tap **Explore in 3D** beside any note. The matching concept opens in the lab, and its explanation is shown and read aloud. This includes GPU, spreadsheet formulas, web concepts, network topology and algorithms.
4. When connected, the teacher's chosen topic, model, component and activity controls also appear on Board. If both devices speak at once, mute Component voice on one device.
5. Use Predict → Try → Explain and the short quiz for understanding checks.

The project has 10 topics, 50 switchable 3D views, 99 note-linked concepts, 20 embedded diagrams and 10 interactive experiments. Content can load without Internet. Teacher/Board pairing requires Internet for PeerJS signaling and a network/browser permitting peer connections. Six-digit codes are classroom conveniences, not private authentication. Browser speech support varies; written explanations always remain visible. The models simplify real systems for teaching.
