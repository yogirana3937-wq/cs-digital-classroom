# CS Digital Classroom — Board startup and connection fix

Upload `index.html`, `teacher.html`, and `board.html` together to the root of your GitHub Pages repository, replacing the old files. All lesson models, activities, and diagrams are embedded in these pages.

## Connect Teacher and Board

1. Open Teacher on the phone. Enter a six-digit code and tap **Start Classroom**. Wait until Teacher shows **Classroom ready**. Keep the Teacher page open.
2. Open Board on the display. Enter the same code and tap **Connect**. Board now shows lesson content even before connecting. If Teacher has not started yet, Board shows **Waiting for teacher** and retries automatically.
3. When Board shows **Connected to Teacher**, change a lesson or model on Teacher. The Board should follow. Tapping a component shows and reads its explanation.
4. If Teacher says **Code already in use**, choose another six-digit code on both devices. If Board keeps waiting, check that Teacher shows ready, both devices have Internet, and both opened the newly uploaded pages. Browser or network restrictions may prevent peer connections.

The 10 topics include 50 switchable 3D views, 99 note-linked concepts, 20 embedded diagrams and 10 activities. Content can load without Internet; cross-device pairing requires Internet for PeerJS signaling and a network that permits peer connections. Room codes are for convenience, not private authentication. Browser speech support varies.
